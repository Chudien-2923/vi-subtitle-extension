Phụ đề tiếng Việt tự nhiên cho video YouTube tiếng Anh ·

1. Nhà cung cấp dịch (API key của bạn)

Bản dịch do mô hình AI bạn chọn thực hiện, gọi trực tiếp bằng API key của bạn. Key chỉ lưu trên máy này. Gemini có gói miễn phí, phù hợp để bắt đầu.

Lấy API key
Dùng các tài khoản bạn đã đăng nhập trong Oh My Pi (omp login), không cần API key. Mở Terminal và chạy cầu nối, để cửa sổ mở trong lúc xem video: 
node omp-bridge.mjs
Tải file omp-bridge.mjs (hoặc chạy npm run omp-bridge trong thư mục mã nguồn). Model dạng anthropic/claude-haiku-5-5, openai-codex/… hoặc @smol. Lưu ý: gói thuê bao (Claude Pro/Max, ChatGPT…) có điều khoản riêng; dịch nhiều video sẽ dùng hạn mức của tài khoản.
Chỉ hỗ trợ localhost / 127.0.0.1. Nếu Ollama báo lỗi quyền truy cập, chạy Ollama với biến môi trường OLLAMA_ORIGINS=chrome-extension://*.
